<h1>Que 1: Kth Permutation</h1>

<h2>Problem Overview</h2>
<p>
An extended version of LeetCode 60 (Permutation Sequence),
where the input array may contain duplicate elements.
</p>

<h2>Approach: Factorial Mathematics</h2>
<p>
Instead of generating all permutations, we calculate the
number of distinct permutations using factorials.
</p>

<h3>Handling Duplicates</h3>
<p>
If an element occurs multiple times, we divide by the
factorial of its frequency.
</p>
